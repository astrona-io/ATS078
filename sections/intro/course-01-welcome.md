# Welcome To The Course

This course is for learners preparing for the Certified Cloud Native Platform Engineering Associate (CNPA) examination from the Cloud Native Computing Foundation (CNCF) and the Linux Foundation. It covers the domain Platform Observability, Security, and Conformance, worth 20% of the published curriculum. The examination tests knowledge through multiple-choice questions. The explanations build the reasoning needed to choose an answer and explain why the alternatives do not fit.

At the end, you can explain and compare the concepts in observability (metrics, logs, events and how to correlate them), secure service communication (service mesh identity, mutual Transport Layer Security (mTLS) and public key infrastructure (PKI)), policy engines for platform governance (admission control, Pod Security Admission and validating admission policy), Kubernetes security essentials (role-based access control (RBAC), authentication and ServiceAccounts) and security in continuous integration and continuous delivery (CI/CD) pipelines (artifact identity by digest, credentials and execution policy). Technical terms and acronyms are defined when they appear. Examples use ordinary applications; names such as `scout`, `probe` and `shuttle` identify workloads rather than changing the technical meaning.

Each section begins with an introduction and learning outcomes. A section has one or two modules, each with a short landing page, deep-dive parts and a summary. The landing page starts a playground: a clean Kubernetes cluster on your own machine, with no task and no grading. A graded lab then asks you to apply what you read, and a capstone lab at the end of each section combines it. Read the examples carefully, identify which component does the work, and predict what changes when a condition changes. Then run the command and compare.

The examination itself is multiple choice, so the hands-on work is there to make the mechanisms concrete. After each section, a knowledge check with original practice questions gives answer feedback. A final knowledge check closes the domain. These questions are independently written and are not copied from the examination.

The examination also covers other domains, such as platform engineering core fundamentals and continuous delivery. This course covers only the observability, security and conformance domain.
