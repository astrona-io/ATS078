# Service Mesh Identity And Policy

This module develops service Mesh Identity And Policy. Use the explanations to connect intended behavior with responsible components and observable evidence.

## Learning Goals

- Distinguish encrypted transport, peer authentication and authorization.
- Explain where mesh components implement communication policy.
- Relate certificate rotation and hop boundaries to trust.
- Identify residual application and retry requirements.
- Explain public keys, private keys and certificate authority trust.
- Distinguish server authentication from mutual TLS.
- Relate identity names, validity and trust chains to verification.
- Describe rotation and compromise recovery for certificate-based identities.

## Before You Start

Examples illustrate declared relationships and reasoning. No execution environment is required or claimed.
