# Authorization And Effective Permissions

This module develops authorization And Effective Permissions. Use the explanations to connect intended behavior with responsible components and observable evidence.

## Learning Goals

- Compare Role, ClusterRole, RoleBinding and ClusterRoleBinding.
- Evaluate namespace scope, verbs, resources and subjects.
- Explain additive grants and indirect privilege.
- Apply least privilege to a workload identity.
- Distinguish established identity from granted API permission.
- Explain ServiceAccount token audience and lifetime.
- Identify unnecessary credential mounting and disclosure paths.
- Relate authentication failure to the actual credential mechanism.

## Before You Start

Examples illustrate declared relationships and reasoning. No execution environment is required or claimed.
