# Summary

Supply chain security protects the path from source and dependencies through build, publication and execution. Identities at each stage have different authority and need appropriate separation.

Verification evidence must refer to the exact deployed artifact and be enforced through a trusted decision point. Missing-evidence behavior, exceptions and later vulnerability or trust changes contribute to the control lifecycle. Artifact assurance does not eliminate application defects.
