# ATS078 — CNPA: Platform Observability, Security, and Conformance

Preparation for the **Platform Observability, Security, and Conformance** domain of **Certified Cloud Native Platform Engineering Associate (CNPA)**.
The published domain weight is **20%**. This repository belongs to
the [ATP016 training path](https://github.com/astrona-io/ATP016).
